# TEST-06: Usability Test

This is a manual usability test for the participant quiz controls and admin question list. Run it with the application pages that load the Sprint 1 and Sprint 2 modules.

## Test setup

- Use a quiz with at least three questions and two answer choices per question.
- Start with no answers selected.
- Open the admin question-list page with at least two questions.
- Ask a participant who has not used the interface before to complete the tasks without coaching.

## Tasks and acceptance criteria

| # | Task | Pass criteria | Result / notes |
|---|------|---------------|----------------|
| 1 | Select an answer for Question 1. | The selected choice is visibly selected and remains selected when revisiting Question 1. | |
| 2 | Move forward and backward between questions. | Previous/Next controls work; Previous is disabled on the first question and Next on the last. | |
| 3 | Use the numbered question controls. | The requested question opens, the current question is identifiable, and answered questions are distinguishable. | |
| 4 | Exit the quiz, then cancel the confirmation. | The quiz stays open and the selected answers remain available. | |
| 5 | Exit again and confirm. | The exit callback runs and the host page can leave the quiz. | |
| 6 | Open the admin question list. | Question text is readable, displayed as a list, and an empty list has a clear message. | |
